# CONTEXT

Журнал решений и изменений. Новые записи сверху.

## 2026-10-02 — feat/workspace-ui

Вход, несколько исполнителей и рабочая оболочка.

- Пароль хранится как scrypt. Сессия — случайный токен на 30 дней. Заголовок `X-User-Id` больше не принимается. У пользователей без пароля он становится `tracker`.
- Ключ проекта `TASK`, в шапке чёрный знак на светлой плашке и подпись «Наш трекер».
- Слева проекты и команда. Канбан, бэклог и роудмап переключаются над доской. Меню сворачивается.
- На канбане левая колонка — «Бэклог». На экране бэклога очередь слева, спринты рядом, карточки перетаскиваются. Зона сброса подсвечивается рамкой.
- У карточки несколько исполнителей, на карточке фамилия и инициалы. Файлы копятся в очереди и прикрепляются кнопкой.

## 2026-10-02 — feat/onboarding

Короткая инструкция при первом заходе.

- Пять шагов: кто вы, доска, карточка, бэклог, сроки. Без отдельного тура по экрану.
- Закрытие запоминается в браузере. Снова открывается пунктом «Как пользоваться» в боковой панели.

## 2026-10-01 — feat/planning

Бэклог, спринты и roadmap.

- Активный спринт один. Закрытие оставляет сделанное в спринте, остальное возвращает в бэклог.
- Запланированный спринт можно запустить, поправить или удалить. Закрытый не редактируется.
- Шкала строится по дням. Карточки без дат перечислены под ней, а не пропадают.

## 2026-10-01 — feat/board

Доска и карточка.

- Четыре колонки, перетаскивание выключено, пока включён фильтр, чтобы не переставлять скрытые карточки.
- Панель справа: описание, приоритет, метки, исполнитель, спринт, оценка, даты, чеклист, файлы, комментарии, списание и история.
- Поля карточки сохраняются сами, с короткой паузой. Описание в историю попадает только как факт правки.
- Имя проекта в сиде — «Внутренний трекер», ключ по-прежнему RKS.

## 2026-10-01 — feat/api

Сервер по SPEKA.

- Схема PostgreSQL, сид только на пустой базе: проект RKS, шесть человек, три спринта, четырнадцать карточек.
- Номер карточки берётся под advisory lock, чтобы два одновременных создания не получили один ключ.
- История не хранит старый текст описания, только факт правки.
- Файлы лежат в `server/uploads`, при удалении карточки удаляются и с диска.
- API слушает порт 3088: 3001 на этой машине уже был занят. Клиентский прокси смотрит туда же.

## 2026-10-01 — chore/scaffold

Каркас без предметной логики.

- PostgreSQL поднимается через Docker Compose, учётка только для локальной базы.
- Сервер пока отвечает на `/api/health`.
- Клиент — пустой тёмный каркас: боковая панель, знак куба, системный шрифт. Стили дальше наращиваются в этом же `styles.css`.

## 2026-10-01 — docs/specification

Проект был пустым. До кода зафиксирована спецификация.

- Один проект `RKS`, команда до 40 человек, без паролей: человек выбирается в интерфейсе.
- Два типа карточек одного уровня, задача и баг. Вложенности нет.
- Колонки: к выполнению, в работе, ревью, готово.
- Внешняя папка называется `rks_jira_nuxt`, клиент при этом Vue 3, не Nuxt: так задан стек.
- Визуальный язык: тёмный, тихий, почти без цвета, пустое состояние с контурным кубом. Ориентир — спокойный тёмный редактор, а не классическая разноцветная доска.
